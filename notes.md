## Imp commands
- Postgress installation sample command
    `docker run --name my-postgres -e POSTGRES_USER=<myuser> -e POSTGRES_PASSWORD=<mypassword> -p 5432:5432 -d postgres`

- command to generate prisma file
    `npx prisma generate`

- command to migrate prisma
    `npx prisma migrate`
    
- command to sync changes with db 
    `npx prisma db push`
